# AGENTS.md

## Purpose
This repository is a small **GitHub Pages** game portal (HTML/CSS/Vanilla JS only).

## Core Policy
- **No backend** (no server/database/API dependency required to run).
- **Vanilla JS only** (no frameworks/build tooling unless explicitly requested).
- **Mobile-first responsive UI** for phone + desktop.
- Keep **Ko-fi** widget and **AdSense** placeholder integration intact.
- **Avoid overengineering**: simple structure, small files, readable code.
- Prioritize **small, quick-play browser games** over heavy titles.
- **Do not break existing features** (search, filters, modal play, static pages, branding).

## Change Guidelines
- Prefer incremental edits over full rewrites.
- Keep file structure GitHub Pages-friendly.
- Validate with lightweight checks before commit.
