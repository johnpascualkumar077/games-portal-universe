# AGENTS.md

## Purpose
This repository manages small browser games and a game portal published via GitHub Pages.

## Stack
- HTML / CSS / Vanilla JavaScript only
- No backend (no server, database, or API dependency)
- GitHub Pages compatible structure

## Principles
- **Speed > simplicity > polish**
- Prefer small, quick-play browser games over large complex titles
- Keep UI simple and mobile-friendly
- Maintain Ko-fi widget and AdSense placeholder integration
- Do not break existing working features (search, filters, modal, navigation, branding)
- Favor small, fast-to-ship changes over overengineered solutions
